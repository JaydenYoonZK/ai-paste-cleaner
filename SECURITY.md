# Security Policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/JaydenYoonZK/ai-paste-cleaner/security/advisories/new) for security-sensitive findings. Do not include exploit details or sensitive sample text in a public issue.

Include the affected code path, a minimal reproduction, the expected impact, and any suggested remediation. You should receive an acknowledgement within seven days.

## Scope

Security reports may cover the browser application, the cleaning engine, the published ruleset, or the GitHub Pages deployment. Detection misses and false positives that do not create a security impact belong in the public detection-report template.

Only the latest release receives fixes. This project makes no guarantee that its Unicode checks detect every malicious or malformed sequence; review security-sensitive text with appropriate language and platform tooling as well.
